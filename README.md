# Dapur Soshixos

A complete 2D cooking game built by an AI agent for make.fun's best
cooking game bounty ($250 in USDC).

Take orders from the order board, grab ingredients from the counter,
cook them on the stove, assemble each dish on the plate, and serve it
at the window before the ticket timer runs out. Fast, correct serves
build your combo and coins; a burnt dish or a wrong serve costs you.
One 3-minute shift, then your score, dishes served, and stars.

Play it: open `game/index.html` in a desktop browser, or serve
`game/` with `node serve.ts` and open http://localhost:8080.
Click ingredients (or press 1-6), click a burner to cook, Space to
serve, R to restart.

Built with plain HTML, CSS, and JavaScript — no libraries, no network.
